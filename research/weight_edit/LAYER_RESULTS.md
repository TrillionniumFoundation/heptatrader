# Current100k：Transformer 层归因与局部干预

本轮已将定位深入到 ModernBERT 的内部子层，并用完整 54 条冻结历史输入核实。最明显的局部方向压缩发生在**零基 `block12`（第 13 个 Transformer block）的 MLP 残差**，但小样本因果干预显示，它不能单独解释最终输出近常数。后续层会恢复部分表示差异，直接削弱这一共同方向也没有显著扩大最终表示的差异。

这是一项历史输入上的机制诊断。没有训练新模型，没有修改原权重、冻结候选、评估登记或生产服务，也没有新订单或独立未来收益结论。

## 范围与一致性

- 模型：冻结的 ModernBERT 编码器，22 个 Transformer blocks、768 维输出。
- 全量：原来的 54 条历史输入，顺序和内容由冻结清单校验。
- 观察点：embedding、每个 block 的输出，以及独立的 `final_norm`，共 24 个阶段。
- 子层：另外拆开 block0、block12、block18 的输入、Attention 输出、Attention 残差后状态、MLP 输出、最终残差后状态。
- 所有 54 条输入的最终特征与原 FP32 缓存逐值一致，最大绝对误差为 **0**；三个被检查 block 的残差重建也逐值一致。
- 运行：CPU 两线程，不初始化 GPU。完整 54 行诊断耗时 **117.47 秒**，峰值 RSS **2,770,993,152 字节**。

对比用的几何量是

\[
x_i=\operatorname{normalize}(\operatorname{masked\_mean}(h_i)),\qquad
R=\sqrt{\frac1n\sum_i\|x_i-\bar x\|_2^2}.
\]

这里的 `R` 只表示不同输入在表示空间中的分散程度。更大的 `R` 不能直接解释为更好的收益预测。

## 1. 局部压缩来自第 13 个 block 的 MLP

下面各数值来自同一批 54 条冻结输入。

| 阶段 | 归一化表示中心 RMS | 未归一化池化向量的平均范数 |
| --- | ---: | ---: |
| embedding | 0.078138 | 14.218 |
| block0 输出 | 0.053227 | 22.441 |
| block11 输出／block12 输入 | 0.066592 | 40.381 |
| block12 加入 Attention 残差后 | 0.077607 | 47.588 |
| block12 加入 MLP 残差后 | 0.037738 | 145.864 |
| block17 输出 | 0.064433 | 176.756 |
| block21 输出 | 0.062216 | 287.497 |
| final_norm 后，即原最终特征 | 0.059563 | 41.159 |

第 13 个 block 的 Attention 将局部方向差异扩大；随后 MLP 加入一个范数很大的近似共同方向。这个 MLP 池化输出的平均范数为 **138.941917**，不同历史输入之间方向余弦的中位数为 **0.999749**，方向中心 RMS 为 **0.016438**。

这种共同方向解释了局部角度分散程度下降，但不能据此判定权重损坏。该层残差后的未归一化中心 RMS 实际从 Attention 后的 **3.726908** 上升到 **11.038524**，说明原始激活差异并没有简单消失；较大的共同分量和径向变化改变了归一化后的几何关系。后续 block13–17 又恢复了相当一部分方向差异。

`final_norm` 将中心 RMS 从 **0.062216** 变为 **0.059563**，不是本轮观察到的主要局部压缩点。

## 2. 内存干预没有证明“删掉这一方向就能修好”

对事先固定的历史行索引 0、18、36、53，每条都运行原输入与 BUY/SELL 翻转输入，比较三种条件，共 24 次完整前向：

1. 原模型。
2. 仅在 block12 MLP 输出处，移除一半沿共同方向的分量。方向由全部 54 条历史输入的 MLP 平均池化输出计算，未使用标签。
3. 将该 MLP 输出整体置零，作为较强的因果定位探针。

所有干预通过仅存在于当前进程中的 forward hook 完成，没有写回权重。

| 条件 | 最终表示中心 RMS | 相对原模型变化 | 保持原读出头时的预测标准差 |
| --- | ---: | ---: | ---: |
| 原模型 | 0.060204314 | — | $0.007927 |
| block12 MLP 共同方向分量减半 | 0.060338884 | +0.22% | $0.013489 |
| block12 MLP 输出整体置零 | 0.063871003 | +6.09% | $0.012945 |

共同方向减半对最终表示分散程度的影响很小，行动翻转敏感性也有升有降。整个 MLP 置零的影响更大，但仍不足以说明获得了有效预测信息。保持不变的读出头面对已经改变的特征分布，其输出变化也不能当作质量改善。

这组干预耗时 **55.44 秒**，峰值 RSS **2,810,261,504 字节**，未初始化 GPU。

## 3. 池化也在稀释行动信号

最初的独立逐层探针在两条固定请求上得到：

| 行索引 | 最终层行动 token 的归一化向量变化 | 全 token 池化后向量变化 |
| --- | ---: | ---: |
| 0 | 0.590049 | 0.013863 |
| 53 | 0.666488 | 0.013505 |

这两条输入都包含 1,332 个有效 token，其中行情区间占 1,173 个，行动本身只占 1 个 token。因此，全局平均池化会显著减弱局部行动变化。不过，单独抽取行动 token 是不同的特征接口，不能直接作为已验证替代方案。

该初始探针完成了 9 个前向，耗时 **23.82 秒**。第 0 行的走势反转构造产生了 2,080 token，超出既定 2,048 上限，已明确跳过，未截断后冒充同一测试。

## 4. 对下一步的实际意义

当前证据不支持把某个 Transformer block 的一组权重直接判为错误。已经找到了可复现的局部机制：原输入与平均池化本就产生高度相似的向量，特定 MLP 又放大共同方向；后续层还会重新组织这些表示。

本轮没有把内部消融加入原冻结候选集。已有候选的独立未来比较继续使用原来的候选身份和规则。内部层或池化的改动如果以后成为新候选，应以独立身份登记，并与已有简单基线比较，不能借这批已经查看过标签的历史输入宣称有效。

- `current100k_block12_intervention.py`：仅在内存中运行的机制干预；SHA-256 为 `d94bb8afaf74c92c9de6f7b23ad4d7580f164a29c6243c0e71d68e5c96166a33`。
- `layer-results-20261103.json`：汇总数值、运行成本、原始报告和源码哈希，不含输入文本或特征张量；与实际运行产生的 `PUBLIC_SUMMARY.json` 逐字节一致，SHA-256 为 `9619027a704a7dd552c85d3045a97803a14d7094af95cd56ed456a8ad5952b2b`。

运行时需要原冻结 study、模型 runtime、base，以及已固定的 Python 环境：

```bash
python current100k_layer_diagnosis.py \
  --study /path/to/frozen-study \
  --runtime /path/to/pinned-runtime \
  --base /path/to/pinned-base \
  --out /path/to/new-layer-output \
  --all-original-rows

python current100k_block12_intervention.py \
  --study /path/to/frozen-study \
  --runtime /path/to/pinned-runtime \
  --base /path/to/pinned-base \
  --layer_run /path/to/new-layer-output \
  --out /path/to/new-intervention-output
```

输出目录必须是新的或空目录。两个脚本都会先核对冻结身份，并拒绝覆盖已有输出。
