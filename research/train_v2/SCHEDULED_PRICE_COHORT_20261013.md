## Completion and failure rules

- New source cohort and fixed timer roster must be sealed before slot 0
  begins. Existing missed or open campaigns reject timer-roster creation.
- All three future anchors and the actual original code hashes are checked
  at final use. A forged event/slot, wrong code SHA, changed campaign JSON,
  symlinked private path, early timer, late timer or duplicate result is
  refused rather than massaged into a successful sample.
- One invocation attempts an original source capture exactly once.
  It stores a create-once result with exact start/finish times, source
  input byte SHA on success or explicit error reason on failure.
  Even a successfully sealed source remains PRICE INPUT ONLY with every
  future horizon pending, not a model prediction or independent signed
  price mark.
- Unexpected source integrity failures do not trigger blind retry.
  No missed source is converted to no-quote/no-trade earnings or
  used to refit models and then declared out of sample.
- Host timer states, actual systemd trigger times and exit code/log
  must be inspected separately; sealed local schedule JSON alone does
  not prove that the host executed a task.
