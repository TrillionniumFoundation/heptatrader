# Train V2 2026-10-13: finite scheduled, price-only PAPER source capture

This is an independently declared, optional new price-observation method,
not a modification of the existing prospective campaign. All original
trading, old signed trials, Laya HOLD/source contracts and broker permissions
remain unchanged. No Canonical Agentd Owner, economic strategy or model
inference is authorized.

## Failure addressed

The first existing manual no-trade price cohort on 2026-10-13 was registered
before its original 00:20 (UTC+8) anchor, but the manual capture started
at 00:20:17, one second after the immutable anchor+16s deadline. That
failed original source input remains MISSED_NO_OPERATOR_CAPTURE_NOT_NO_QUOTE;
its label and economic result are absent. Existing future slots at 01:40
and 03:00 are not changed or reclassified.

A separate NEW cohort may use an opt-in fixed roster of three exact
one-shot timer invocations, registered and fsynced BEFORE its first
original price-only input. The frozen original cohort source module is
unchanged. A companion schedule has its own code SHA256, the exact
original cohort/campaign file SHA, local-only preregistered period and
source, three UTC slot launches and a fixed 12-second process timeout.

The systemd user manager is responsible for actual timer delivery;
the Python module DOES NOT mint a service, run continually, enter any
broker trading profile or start a training job. Each one-shot is
additionally bounded by the original campaign's [anchor+1s,anchor+16s]
window. A timer launch at anchor+5s is nominal; any misfire after
anchor+16s is rejected and must not be backdated or retried.

A source capture reads the already-running PAPER original locally
hash-chained quote writer through its exact existing original-source
adapter, then writes an immutable PREOUTCOME source receipt ONLY.
It cannot predict a trading action, label an outcome or place orders.
An independent original post-maturity price-only observer is a
separate read-only step. There is no genuine model effect or eligible
economic alpha from this research method.

## Completion and failure rules

- New source cohort and fixed timer roster must be sealed before slot 0
  begins. Existing missed or open campaigns reject timer-roster creation.
- All three future anchors and the actual original code hashes are checked
  at final use. A forged event/slot, wrong code SHA, changed campaign JSON,
  symlinked private path, early timer, late timer or duplicate result is
  refused rather than massaged into a successful sample.
- One invocation attempts an original source capture exactly once.
  It stores a create-once result with exact start/finish times, source
  input byte SHA on success or explicit error reason on failure.
  Even a successfully sealed source remains PRICE INPUT ONLY with every
  future horizon pending, not a model prediction or independent signed
  price mark.
- Unexpected source integrity failures do not trigger blind retry.
  No missed source is converted to no-quote/no-trade earnings or
  used to refit models and then declared out of sample.
- Host timer states, actual systemd trigger times and exit code/log
  must be inspected separately; sealed local schedule JSON alone does
  not prove that the host executed a task.
