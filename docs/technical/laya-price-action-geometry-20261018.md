# Pocket4 Laya：价格几何与 ACT 参数化诊断（2026-10-18 UTC）

## 结论与决定

本轮价格和 ACT 研究均已完成。价格问题主要落在固定偏好、选项顺序依赖，以及原可调通道和有效权重预算不足以修正主要错误。ACT 的 A/B 参数化与现有 AdamW 配方确实压缩了有效更新；换成等价的直接 margin 参数后更新明显增大，但新增训练收益主要仍来自共同 margin 调整。

- **价格：**固定 32 条训练数据中原模型正确 2 条。联合两层的保守上界排除了 30 个错例中 29 个被纠正的可能性，故在相同输入、parent、可调支持和范数参考下，正确数最多达到 3 / 32。
- **优化器：**固定最后一层特征后，优化整个最终共享向量得到 NLL 2.38040279；原完整半径的凸下界为 2.38040128，仍远差于固定训练先验的 1.50203273。继续优化这个末层无法填补主要差距。
- **顺序：**循环移动一格和反序后，恢复相同价格语义仍分别有 25 / 32、29 / 32 行改变赢家。语义对齐比 slot 对齐更接近原输出，所以证据同时支持语义响应与顺序依赖。
- **ACT：**等价 direct-\(\theta\) 在同样 16 步后的最终有效权重位移为原 LoRA 的 **33.98 倍**，NLL 从 0.23208324 降到 0.23193297；其中 **97.44%** 的改善可由实际共同 margin 移动解释。绝对改善仍很小，尚无条件泛化或交易优势证据。

所有代码、数据、GPU 执行和证据均位于 Pocket4。本轮没有旧 holdout forward，没有模型晋升或订单发送。两次真正的 GPU 实验都使用原资源门槛、Value 优先级和全局单重任务锁；未获准的观察全部保留。

## 2. 固定价格偏好与旧 16 步终点

令 \(z_{ij}\) 为第 \(i\) 行、第 \(j\) 个语义类别的 logit。去除每行共同平移后，分解为固定选项均值和剩余项：

\[
L_{ij}=z_{ij}-\overline z_i,\quad
b_j=\operatorname{mean}_i L_{ij},\quad
R_{ij}=L_{ij}-b_j.
\]

固定选项均值解释了行中心化 logits 平方能量的 **70.3833%**。这是能量分解，不是损失归因比例，也不能单独区分语义和位置偏好。

原预测计数为 `[21, 0, 0, 0, 5, 4, 2]`。共有 23 / 32 次预测落在本子集没有真实标签的第 0 或第 6 档。原模型给第 0 档的平均概率为 **31.5663%**，固定 178 行训练池的平滑先验只有 **0.2755%**。

|---|---:|---:|---:|
| 原 parent | 2.39550151 | 1.00022939 | 2 / 32 |
| 旧 ACT 权重 0.01、16 步终点 | 2.39528594 | 1.00015777 | 2 / 32 |
| 均匀七类常数基线，解析值 | 1.94591015 | 0.85714286 | 不以任意打破平局的正确数评价 |
| 固定 178 行训练先验 | 1.50203273 | 0.75265521 | 12 / 32 |
| 原预算内最终共享向量参考 | 2.38040279 | 0.99532993 | 2 / 32 |

相对 parent 的实际有效权重变化为第一价格层 **0.00088340**、最终层 **0.00033536**；NLL 只改善 **0.00021556**，预测计数完全相同。

旧终点的 raw logit 改变范数为 0.023701，移除每行共同平移后只有 0.003302。共同平移不改变 softmax，因此不能将参数变化或 raw logit 变化直接当作预测学习充分的证据。

### 固定先验偏移的含义

使用每类 0.5 平滑的固定 178 行训练先验 \(\pi\)，只在优化前拟合一次：

\[
c_j=\log\pi_j-b_j-\operatorname{mean}_k(\log\pi_k-b_k).
\]

拟合 \(b\) 使用 step-0 logits，没有使用每行标签；训练池类别计数本身属于有标签的训练信息。这调整平均相对 logit 的形状，**不保证平均预测概率精确等于先验**。

偏移位于旧 adapter 范数配置之外，已写入独立研究 recipe。其训练集优势没有被视为独立泛化或交易优势。

## 3. 原可调范围的纠错上界

| 算子 | 当前可变范围 |
|---|---|
| Encoder、Transformer head、LayerNorm | 固定 |
| `scorer.1`：768 → 768 | 仅第 0–3 个隐藏单元，LoRA rank 2 |
| GELU | 固定，`approximate="none"` |
| `scorer.3`：768 → 1，共享于七个选项 | 单输出行，LoRA rank 1 |

“前四个”是隐藏单元，不是四个价格类别。这四个单元对行中心化价格分数的贡献范数只有 **0.00432452**，全部价格分数的对应范数约 **10.7603**。观测到的 GELU 导数范围是 **−0.11087 至 1.02696**，不能把它们统称为死单元；问题在于允许的改变对最终分数的作用很弱。

范数参考包含原 parent 的 LoRA 有效更新。每层相对上限为 0.005，全局为 0.0025。

| 层 | Parent 平方范数 | 允许变化范数 |
|---|---:|---:|
| 第一价格层 | 383.31945727 | 0.09789273 |
| 最终价格层 | 0.17342025 | 0.00208219 |
| ACT 最终层 | 0.68532137 | 0.00413921 |

平方范数需要先开方，再乘相对上限。

对原错例，设原赢家为 \(p\)、真实类别为 \(y\)，\(x\) 为固定 LayerNorm 输出、\(h\) 为 parent GELU 后特征、\(w_S\) 为最终层在四个可调单元上的 parent 有效权重，则：

\[
|\Delta(z_y-z_p)|
\le R_3\|h_y-h_p\|
 +(\|w_S\|+R_3)\,1.13R_1(\|x_y\|+\|x_p\|).
\]

该保守界包括两层同时改变产生的交叉项。1.13 是精确 GELU 导数绝对值上界的安全取值。未使用额外全局限制只会放宽允许域。

**30 个原错例中有 29 个的差距超过上界，最小剩余差距为 0.32069823。** 因而同一固定输入、parent、支持和预算下，最多从 2 / 32 达到 3 / 32。更多轮训练仍可能改善置信度或纠正剩下那个未被排除的错误。

额外类别偏移与变更排列属于不同读出配置，不受这一原始更新上界约束。

此结论不适用于新表示、改变输入协议、滚动更换 parent 并重置范数参考后的累计训练；也不是对任意病态 FP32 因子化舍入的认证。

### 最终向量凸参考

最终权重为 \(1\times768\)，任意这样的线性向量已经至多 rank 1。提高末层 LoRA rank 可以改变优化参数化，却不能扩大固定特征上的线性函数集合。

本轮直接优化整个最终向量增量 \(\delta\)，固定第一价格层及全部特征，目标为这 32 行的平均价格 CE。它是功能空间参考，不是 resident 的 16 步 AdamW 或带可选 teacher KL 的完整训练配方。

L2 球内凸目标的证书为：

\[
D(\delta)=\delta^\top\nabla f(\delta)+R\|\nabla f(\delta)\|,\quad
f^\star\ge f(\delta)-D(\delta).
\]

为打包预留舍入余量，实际求解半径为原半径的 0.9999。两条参考一次投影后均达到预定 gap 阈值 \(10^{-7}\)，没有机械运行满 512 次。

| 参考 | 缩小半径实际 gap | 原完整半径 gap | 原完整半径 NLL 下界 |
|---|---:|---:|---:|
| Raw | \(2.85\times10^{-10}\) | \(1.50\times10^{-6}\) | 2.38040128 |
| 固定价格先验偏移 | \(9.78\times10^{-10}\) | \(2.20\times10^{-7}\) | 1.49337618 |

这些是固定缓存特征目标的证书，不是两层联合训练的 NLL 下界；联合纠错结论来自单独的扰动界。FP64 gap 也不能直接当作完整 FP32 执行链的认证精度。

两个向量均打包回原 rank-1 模块、保存并重新加载。最终层实际相对变化约 **0.00499950**，原第一层未变，全局约束通过。

## 5. NLL 与标签配对描述量

定义 \(G=N^{-1}\sum_i R_{i,y_i}\)。它等于固定 logits 下随机重新配对相同标签多重集合的期望 NLL，减去实际 NLL。这里使用解析期望，没有进行显著性检验。每组结果按自身列均值计算，任何固定的每类偏移均不改变 \(G\)。

| 价格条件 | 优化前 \(G\) | 优化后 \(G\) |
|---|---:|---:|
| Raw 最终向量参考 | 0.05443498 | 0.05324837 |
| 固定价格先验偏移参考 | 0.05443498 | 0.05324943 |

NLL 下降没有伴随这个标签配对描述量增强，结果更符合分布或置信度调整。**\(G\) 依赖 logit 尺度，不是独立的适当评分规则。** 缩小过强的剩余 logit 可以同时降低 \(G\) 和 NLL；因此不能仅据 \(G\) 下降断言排序或泛化变差，也不将最大化 \(G\) 改为训练目标。

## 6. ACT：有效步长问题被复现，但条件收益仍小

沿用上一轮已固定的 CLS768 无仿射 LayerNorm、原四个价格特征及固定 ACT margin 偏移 **−33.873892842640856**。没有重新拟合截距，也没有使用本轮改变后的价格特征。

实际加载权重确认 parent 的 action B 和有效增量均为零。比较：

- 原 LoRA：原随机 A、零 B，训练 66 个 A/B 参数。
- Direct-\(\theta\)：A 初始化为零，固定 \(B=[+1/2,-1/2]^\top\)，只训练 64 维 \(\theta\)。

后者仍通过原 `MaskedActionLinear` 执行：

\[
\Delta W=
\begin{bmatrix}\theta^\top/2\\-\theta^\top/2\end{bmatrix},\quad
\Delta m_i=\theta^\top h_{i,64},\quad
\|\Delta W\|_F=\|\theta\|/\sqrt2.
\]

在零 parent 有效增量前提下，原 rank-1 adapter 也能表达任意这样的 margin；对称表示不增加有用的二分类函数空间。两臂保持同样 32 / B2 / 16 顺序、AdamW learning rate \(10^{-4}\)、betas (0.9, 0.999)、eps \(10^{-8}\)、weight decay 0、ACT loss 权重 0.01、clip 1 和原范数检查。相同名义学习率不代表相同有效权重学习率。

| ACT 配置 | NLL | Brier | 有效 \(\Delta W\) | 使用原上限 |
|---|---:|---:|---:|---:|
| 共同 step 0 | 0.2320832416 | 0.1168470165 | 0 | 0% |
| 原 LoRA，16 步 | 0.2320829371 | 0.1168469394 | 0.0000205195 | 0.496% |
| Direct-\(\theta\)，16 步 | 0.2319329699 | 0.1168090687 | 0.0006973066 | 16.846% |

两臂均 16 次尝试全部接受、0 回滚、0 梯度裁剪触发。旧 LoRA step 0、step 16 logits 与 A/B 全部精确重放；其序列化 SHA 与上一轮相同。两臂保存后重新加载原模块的 logit 差均为 0。

Direct 在 16 步后的最终有效权重位移是原 LoRA 的 **33.98 倍**，这不是逐步更新、预测质量或训练吞吐的倍数。NLL 的绝对改善为 **0.00015027**，约占初始 NLL 的 0.065%；不以相对旧微小改善的巨大倍数替代绝对量。

### 为什么 A/B 更新受限

原 B 为零时，首步 A 梯度实际为零；有用 margin 更新只能沿原 A 方向。首批完整 \(\theta\) 梯度投影到这个方向的范数比例只有 **11.275%**。原 LoRA 首步有效方向与负完整梯度的余弦为 **0.11275**；direct 首步为 **0.59610**。这是坐标与优化器配方的差异，不是末层缺乏 rank-1 表达能力。

对 Adam 非零二阶状态坐标，统计
\(\epsilon/(\sqrt{\widehat v}+\epsilon)\)，并排除全零状态坐标：

| 参数 | 活跃坐标 epsilon 比例的跨步均值 |
|---|---:|
| 原 LoRA A | 0.31713 |
| 原 LoRA B | 0.0000223 |
| Direct \(\theta\) | 0.00652 |

原 A 有 272 / 945 个活跃“坐标 × 步”观察中，epsilon 占分母至少一半。这说明 epsilon 参与了原 A 的更新缩放；没有额外对照时，不能将其说成唯一原因。此次没有扩展 epsilon、学习率或截距扫描。

### 改善的主要部分仍是共同 margin

训练池 ACT 先验为 **9.5 / 179 = 5.3073%**，本子集 ACT 比例为 **2 / 32 = 6.25%**。Direct 的平均 ACT 概率从 **5.30726%** 移至 **5.38946%**，两臂仍全部选择 ESCALATE。

使用实际训练产生的平均 margin 变化，额外计算只施加这个共同变化的缓存反事实；这不重新拟合截距，也不构成新实验臂：

| ACT 配置 | 总 NLL 改善 | 共同 margin 单独解释的改善 | 逐行差异额外改善 | \(\Delta G\) |
|---|---:|---:|---:|---:|
| 原 LoRA | \(3.04\times10^{-7}\) | \(3.32\times10^{-7}\) | \(-2.79\times10^{-8}\) | \(-2.79\times10^{-8}\) |
| Direct \(\theta\) | \(1.5027\times10^{-4}\) | \(1.4642\times10^{-4}\) | \(3.8509\times10^{-6}\) | \(3.8892\times10^{-6}\) |

Direct 的 **97.44%** NLL 改善可由共同 margin 移动解释。剩余是这批训练行上的很小改善，只有两个 ACT 正例，不能视为条件泛化突破。ACT 标签表示原冻结价格父模型的答案正确性，不是交易许可。
