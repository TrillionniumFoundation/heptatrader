## Concrete v3 hardening

The v2 observer already uses Linux inotify to react to native original
*.jsonl appends, while excluding health-only records, and distinguishes
provisional BUY/SELL predictions from independently original-RESPONSE
qualified forecasts. It refuses responses occurring before a prediction's
actual original sealed wallclock, and later scores only actual executed
direction after original OMS execution and USD commission settlement.

The v3 version adds a **hard original request-id validation** to the source
parser and every dynamically constructed evidence filename: only the
exact original producer UUID4-hex shape, [0-9a-f]{32}, is allowed.
Rejected source IDs or altered prediction-receipt filenames cannot be
used to traverse out of the private research directory or contaminate
the future denominator.

v3 has its own fixed protocol version, own immutable new model/program
freeze and distinct private output root. It does not overwrite v2 source,
its freeze, historical baseline or any original producer source.

This is a **synthetic end-to-end engineering rehearsal**, NOT a real
