# Hepta Modular Runtime Global Development Roadmap V2

Status: current normative roadmap
Applies to: all active development workstreams
Verification: milestone, gap and workstream registries plus same-revision evidence
Authority: single global development roadmap

本路线图只定义阶段目标、依赖和出口；实时状态由 JSON registry 与 evidence 派生。

```text
capability-free research
  + shard-aware data/feature plane
  + isolated strategy modules
  + global decision plane
  + unique Execution authority
  + independent management control plane
```

| ID | 里程碑 | 核心出口 |
|---|---|---|
| M0 | Canonical Truth Consolidation | 唯一文档权威、历史正文清除、状态不再手填 |
| M1 | Documentation Control Plane | document/capability/module/contract/gap registries |
| M2 | Modular Runtime Foundation | one target per module、DAG、独立构建测试 |
| M3 | Typed Data and Concurrency | typed state、numeric policy、shards、deterministic concurrency |
| M4 | Global Decision Shadow | Proposal → Optimizer → AllocationPlan → Execution shadow |
| M5 | Active Multi-Agent Simulator | lifecycle、capital allocation、fault isolation |
| M6 | IB PAPER Qualification | contract parity、真实资格认证、soak、rollback |
| M7 | Team-Scale Development | team ownership、merge queue、module SLO 和 impact closure |

先完成 M0/M1；M2 前保持 monorepo；M3 前不把高频数据塞进控制面 IPC；M4 先在 deterministic Simulator shadow 闭环；M5 前不宣称 multi-Agent allocator 可用；M6 使用真实 IB PAPER 和 exact artifact evidence；LIVE 始终是独立 O4 项目。
