# IB FX 多策略并发（fx_trend + fx_scalping）最小闭环

本文档说明如何在 `HeptaTrader` 的 IB 模式下同时启用两个外汇策略并做 paper 模拟测试。

## 启用开关

- `HEPTA_IB_STRATEGY`
  - 为空：不启用策略引擎（保持原有行为）
  - 可选值：`fx_trend`、`fx_scalping`
  - 支持并发：`HEPTA_IB_STRATEGY=fx_trend,fx_scalping`

## 参数（两套策略都支持）

### fx_trend

- `HEPTA_IB_FX_TREND_FAST`
- `HEPTA_IB_FX_TREND_SLOW`
- `HEPTA_IB_FX_TREND_SIGNAL_INTERVAL`（秒）
- `HEPTA_IB_FX_TREND_MAX_POSITION`
- `HEPTA_IB_FX_TREND_STOP_LOSS_BPS`
- `HEPTA_IB_FX_TREND_COOLDOWN_SEC`

### fx_scalping

- `HEPTA_IB_FX_SCALPING_SLOPE_WINDOW`
- `HEPTA_IB_FX_SCALPING_SIGNAL_INTERVAL`（秒）
- `HEPTA_IB_FX_SCALPING_MAX_POSITION`
- `HEPTA_IB_FX_SCALPING_STOP_LOSS_BPS`
- `HEPTA_IB_FX_SCALPING_COOLDOWN_SEC`
- `HEPTA_IB_FX_SCALPING_MIN_SIGNAL_BPS`（别名: `HEPTA_IB_SCALP_MIN_SIGNAL_BPS`）
- `HEPTA_IB_FX_SCALPING_ENTRY_SPREAD_MULT`（别名: `HEPTA_IB_SCALP_ENTRY_SPREAD_MULT`）
- `HEPTA_IB_FX_SCALPING_ENTRY_BUFFER_BPS`（别名: `HEPTA_IB_SCALP_ENTRY_BUFFER_BPS`）
- `HEPTA_IB_FX_SCALPING_EXIT_SIGNAL_BPS`（别名: `HEPTA_IB_SCALP_EXIT_SIGNAL_BPS`）
- `HEPTA_IB_FX_SCALPING_DECAY_EXIT_FRAC`（别名: `HEPTA_IB_SCALP_DECAY_EXIT_FRAC`）

## 直接运行命令（Windows PowerShell）

```powershell
cd D:\quant\HeptaTrader-master
$env:HEPTA_VENUE="IB"
$env:HEPTA_ALLOW_IB_ORDERS="1"            # paper 模拟下单
$env:HEPTA_IB_STRATEGY="fx_trend,fx_scalping"
$env:HEPTA_IB_FX_TREND_FAST="8"
$env:HEPTA_IB_FX_TREND_SLOW="34"
$env:HEPTA_IB_FX_TREND_SIGNAL_INTERVAL="5"
$env:HEPTA_IB_FX_TREND_MAX_POSITION="1000"
$env:HEPTA_IB_FX_TREND_STOP_LOSS_BPS="20"
$env:HEPTA_IB_FX_TREND_COOLDOWN_SEC="10"
$env:HEPTA_IB_FX_SCALPING_SLOPE_WINDOW="12"
$env:HEPTA_IB_FX_SCALPING_SIGNAL_INTERVAL="2"
$env:HEPTA_IB_FX_SCALPING_MAX_POSITION="1000"
$env:HEPTA_IB_FX_SCALPING_STOP_LOSS_BPS="10"
$env:HEPTA_IB_SCALP_MIN_SIGNAL_BPS="0.15"
$env:HEPTA_IB_SCALP_ENTRY_SPREAD_MULT="1.25"
$env:HEPTA_IB_SCALP_ENTRY_BUFFER_BPS="0.10"
$env:HEPTA_IB_SCALP_EXIT_SIGNAL_BPS="0.15"
$env:HEPTA_IB_SCALP_DECAY_EXIT_FRAC="0.50"
$env:HEPTA_IB_FX_SCALPING_COOLDOWN_SEC="5"
.\x64\Release\HeptaTrader.exe
```

## OMS 事件兼容性

策略下单沿用现有事件模型：

- `order_intent`
- `place_sent`
- `status`
- `reject`
- `cancel`（策略当前未主动撤单，保留通道兼容）

事件 `strategy` 字段会标记 `fx_trend` 或 `fx_scalping`，便于并发策略区分。
