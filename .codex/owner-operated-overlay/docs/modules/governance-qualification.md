# Repository governance qualification

Status: RETIRED  
Replacement: [`../adr/0002-owner-operated-repository.md`](../adr/0002-owner-operated-repository.md)

HeptaTrader is an owner-operated self-use system. External repository-governance qualification is not applicable. Teams, CODEOWNERS, mandatory review counts, branch rulesets, Merge Queue, protected governance environments, and governance receipts do not authorize the runtime.

Repository checks remain optional engineering feedback. IB PAPER remains subject to exact-current-main Broker qualification, and LIVE remains unavailable.
